\subsection{Caracterización del decodificador}

Para cada peso entre 0 y 4, se recorre la totalidad de los patrones
de error correspondientes a dicho peso. Estos vectores son generados
en el golden model \texttt{golay\_decoder.ipynb}.

Luego, estos vectores son procesados por un objeto decodificador para
obtener el archivo de vectores
\texttt{outputs/decoder/decoder\_top\_testing/codeword\_with\_errors.txt}.

Este archivo tiene la siguiente convención de vectores.

    def write_codewords_with_error(filename, codeword, max_errors):
        n = len(codeword)
        received_word_array_with_errors = []
        # Convertir codeword [0,1,1,...] -> entero
        codeword_int = int("".join(map(str, codeword)), 2)
        # Todas las posiciones posibles donde colocar los errores, por peso
        # C(24,0) + C(24,1) + C(24,2) + C(24,3) + C(24,4) = 12951
        error_masks = [
            sum(1 << (n - 1 - pos) for pos in error_positions)
            for n_errors in range(max_errors + 1)
            for error_positions in combinations(range(n), n_errors)
        ]
        with open(filename, "w") as file:
            for mask in error_masks:
                received_word = codeword_int ^ mask
                received_bits = np.array(
                    [int(bit) for bit in format(received_word, f"0{n}b")], dtype=np.uint16)
                msg, corrected, uncorrectable = decoder_model.decode(received_bits)
                received_word_array_with_errors.append(received_bits)
                file.write(" ".join([
                    format(received_word, f"0{n}b"),
                    "".join(map(str, msg)),
                    format(mask, f"0{n}b") if uncorrectable is False else format(0, f"0{n}b"),
                    str(int(corrected)),
                    str(int(uncorrectable)),
                ]) + "\n")
        return np.array(received_word_array_with_errors), msg, error_masks, corrected, uncorrectable, len(error_masks)
